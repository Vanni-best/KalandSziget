# 🦊 KalandSziget — BÉTA 1.0

Інтерактивна браузерна гра угорською мовою для дитини від 6 років, що ще не вміє читати.

## Що є в бета-версії

- **Számország** — лічба предметів із поступовим ускладненням до 20.
- **Matekvarázs** — додавання й віднімання з візуальними підказками.
- **Betűerdő** — спочатку дитина чує і знайомиться з літерою, потім знаходить її серед інших.
- **Szókirakó** — складає прості угорські слова з букв, торкаючись великих плиток.
- **Kincsvadászat** — змішана пригода з додатковими зірочками.
- **Matricaalbum** — колекція нагород за прогрес.

Інструкції, пояснення й фідбек озвучуються угорською через `SpeechSynthesis` (`hu-HU`). Є велика кнопка **🔊 Hallgasd meg!** для повторного прослуховування. Інтерфейс гри угорською.

## Як запустити

Просто відкрийте `index.html` у сучасному браузері. Для **найнадійнішого використання на iPhone/iPad**, опублікуйте сайт через HTTPS на GitHub Pages.

## GitHub Pages

1. Створіть новий публічний репозиторій GitHub, наприклад `KalandSziget`.
2. Завантажте файл `index.html` **в корінь** репозиторію (і за бажанням `README.md`).
3. Відкрийте **Settings → Pages → Build and deployment**.
4. Вкажіть **Deploy from a branch**, `main` і `/(root)`. Збережіть.
5. Відкрийте сайт за адресою `https://ВАШ-ЛОГІН.github.io/KalandSziget/` після завершення публікації.

Відкрийте лінк на телефоні дитини. На iPhone у Safari можна вибрати **Поділитися → На початковий екран** — гра матиме власну іконку на екрані.

## Важливо про озвучування

Гра використовує **вбудований у пристрій угорський голос**. Звучання залежить від браузера й встановлених голосів, а не від файлів гри. Озвучування активується натисканням (вимога мобільних браузерів). 

- Натисніть **⚙️ → 🔊 Hang tesztelése** для перевірки.
- У списку **Magyar hang** можна вибрати конкретний доступний угорський голос.
- Якщо пристрій не має якісного угорського голосу, встановіть його в налаштуваннях озвучування операційної системи.
- Якщо автоозвучування не спрацювало, натисніть велику кнопку **🔊 Hallgasd meg!** повторно.
- Для повністю ідентичної озвучки на всіх пристроях у майбутній версії потрібні окремі угорські аудіозаписи.

## Дані й безпека

- Без акаунта, сторонньої аналітики, реклами й зовнішніх скриптів.
- Прогрес зберігається лише в `localStorage` **конкретного браузера**.
- Якщо очистити дані браузера або змінити телефон, прогрес не перенесеться автоматично.
- Озвучування за допомогою браузера може відрізнятися між операційними системами.

## Технології

Весь проєкт у одному файлі `index.html`: HTML + CSS + vanilla JavaScript. Немає залежностей, збірки чи API-ключів. Готовий для GitHub Pages.

## Як додати на домашній екран і грати офлайн

Після публікації на GitHub Pages гра підтримує встановлення як вебдодаток і кешування файлів для повторного запуску без інтернету (за умови, що браузер успішно завантажив і зберіг гру). На iPhone відкрийте посилання в Safari, виберіть **Поділитися → На початковий екран**.

Файли `manifest.webmanifest`, `sw.js` та папку `icons/` треба завантажити в GitHub **разом** з `index.html`. Якщо копіюєте лише `index.html`, гра працюватиме онлайн, але без офлайн-режиму та власної іконки вебдодатка.
